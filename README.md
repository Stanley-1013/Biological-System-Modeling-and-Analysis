## 課程簡介

本課程從系統與數學建模的核心概念出發，系統性地介紹模型建構、數值模擬、驗證與分析的方法，並將其應用於生物系統的定性與定量分析。主要涵蓋：

- 系統模型與建模流程
- 定性與定量模型建構
- 數值方法與參數估計
- 模型驗證與分析
- 隨機模型
- 應用案例研究
