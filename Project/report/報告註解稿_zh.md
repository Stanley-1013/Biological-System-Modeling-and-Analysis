# Part 1 — 葡萄糖的荷爾蒙控制

## 1.1 Cobelli 模型在描述什麼（白話版）

把身體分成三個互相耦合的子系統，總共 **7 個 state variables**（都是「量」，單位是 mg 或 µU，不是濃度）：

| 子系統 | 變數 | 意義 |
|---|---|---|
| Glucose | `g` | 血漿＋細胞外液的葡萄糖（mg） |
| Glucagon | `c` | 血漿＋組織間液的 glucagon（nU） |
| Insulin（5 個 compartment） | `s` | 胰臟「儲存型」insulin |
| | `r` | 胰臟「可立即釋放」insulin（這個之後超重要） |
| | `l` | 肝臟 insulin |
| | `p` | 血漿 insulin |
| | `i` | 組織間液 insulin |

每個量都有對應的濃度（量 ÷ 體積），例如 `ḡ = g/V_b`、`p̄ = p/V_p`。體積 `V_b, V_p, V_l, V_i` 是體重的固定比例。

### tanh flux 的設計（這是整個模型的靈魂）

模型裡所有的回授（feedback）都用 **hyperbolic tangent（tanh）** 來寫成「閘門（gate）」：

- **刺激型（stimulatory）**：`0.5·[1 + tanh(b(Δx̄ + c))]`
- **抑制型（inhibitory）**：`0.5·[1 − tanh(b(Δx̄ + c))]`

要理解它就抓三件事：

1. **Δx̄ 是「對 basal 的偏差」**：不是用絕對濃度，而是「現在濃度 − 基礎濃度」。所以平衡時 Δx̄≈0，閘門停在中間。
2. **tanh 的值域是 ±1**，所以乘上 0.5、加減 1 之後，每個閘門被夾在 **[0, 1]** 之間，是個平滑飽和的開關。
3. **b 決定斜率（開關多快）、c 決定中心（在哪裡開）**。多個閘門相乘 = 「多個限制因子同時要滿足」。

例如胰島素分泌 `F6 = 0.5·a6·[1 + tanh(b6(Δḡ + c6))]·r`：血糖升高（Δḡ>0）→ 閘門打開 → 分泌變多；而且**乘上 r**，代表「你不可能分泌出你手上沒有的 insulin」。這個 `×r` 是後面 Ex2「hump」的關鍵。

### 7 條方程式各代表什麼通量

`dg/dt = NHGB − F3 − F4 − F5 + Ig(t)`，其中：
- `NHGB = F1 − F2`：肝臟淨葡萄糖收支（生產 − 攝取）
- `F3`：腎臟排泄（血糖超過 ~180 mg/100ml 門檻才開）
- `F4`：周邊（肌肉／脂肪）使用，受 insulin 驅動
- `F5`：CNS／紅血球的 sink，幾乎不受 insulin 影響（很大的固定消耗）
- `F6`：胰島素分泌、`F7`：glucagon 分泌、`W`：insulin 合成進儲存池
- `Ig, Ip`：外加的葡萄糖／insulin 輸入（拿來做診斷測試的驅動）

### 一個 transcription（抄寫）修正

課本把腎臟排泄閘門印成用 `b13=0.0275, c13=20`，但那兩個其實是 M1 的「葡萄糖自我抑制」常數。Table 12.2 另外列了 `b31=20, c31=−180`，對應「腎門檻在 ~180 mg/100ml」——這才是生理上對的讀法。所以我用 `b31, c31`，把印錯的 `b13` 當成 typo。

## 1.2 重點誠實發現：為什麼 Table 12.2 直接代入跑不出 Fig 12.4

這是 Part 1 最該講、也最能展現我「不硬湊」的地方。

**問題**：把 Table 12.2 照字面、用「量」的形式代進去，**跑不出課本 Fig 12.4a/b**。而且這不是我單位換算弄錯（量↔濃度差個 `V_b≈140` 的因子，但那只能補上不到 1% 的差距）。兩個量化證據（70 kg 受試者）：

1. **葡萄糖清不掉**：字面上的基礎清除 `F3+F4+F5 ≈ 8.4×10⁻⁴ mg/min`，但基礎葡萄糖量有 `12,810 mg` → 清除時間尺度約 `1.5×10⁷ min`。Fig 12.4 是 ~90 分鐘就恢復，這等於永遠清不掉。
2. **insulin 軸整個塌掉**：基礎血漿 insulin 量 `34,650 µU` 需要 `F6 ≈ 1.6×10⁴ µU/min` 的基礎分泌來維持，但字面上的合成 `W(basal) ≈ 0.017 µU/min`，**差了約 10⁶ 倍**。insulin 跟 glucagon 都歸零，根本做不出 IVGTT 反應。

**為什麼可以做 calibration（而且合理）**：
課本自己說這個模型是「semi-phenomenological…tailored/scaled to a particular patient（半現象學的，會針對特定病人去調比例）」（Haefner §12.3）。所以「選那些被低估／沒定死的 source／clearance 比例尺，把模型坐在某病人的基礎操作點上」——本來就是這個模型的**預期用法**。我做的是最小、保留結構的校正，**沒動任何回授形狀**：

1. **`glucose_flux_scale`（預設 1e5）**：統一乘到四個葡萄糖通量（NHGB, F3, F4, F5），把清除時間尺度調到 ~90 min。因為基礎時 `NHGB = F3+F4+F5`，**共同的比例會互相抵消**，所以基礎穩態跟每個 tanh 形狀完全不變（驗證：scale 取 1、1e3、1e5、1e7，basal residual 都是 3.6e-12；設成 1.0 就還原成字面表格）。
2. **`aw`（insulin 合成）、`a71`（glucagon 分泌）**：選到讓「公佈的臨床基礎值」剛好是精確穩態。沒動任何 tanh 的 b、c，也沒動任何 transfer rate（mij, kij）。
3. **`b52`（F5 的一個常數偏移）**：用那一點點 `NHGB−(F3+F4+F5)` 的不平衡去微調，讓基礎時 `dg/dt=0` 精確成立。這是常數偏移，不是形狀改變。

**校正後驗證**：basal residual 3.6e-12；正常 IVGTT 給出葡萄糖 peak `250 mg/100ml`、~52 min 恢復；血漿 insulin 11→40 µU/ml 後衰減；glucagon 先掉後回；LSODA 與 Radau 一致到 1.6e-4。和 Fig 12.4 在**定性上**吻合。

**我沒有宣稱的事**：我**不**宣稱 1e5、或重校的 aw/a71/b52 就是 Cobelli (1982) 的原始係數。它們是一組「有文件記錄、能從被低估的表格重現課本圖、且完全保留回授結構」的擬合。

## 1.3 逐題註解（Ex1～Ex7）

### Ex1 — 正常 IVGTT，葡萄糖跑去哪？

- **題目**：寫出模型、重現 Fig 12.4a/b，另外畫 glucagon 和肝臟攝取 F2，並回答「大部分葡萄糖跑去哪」。
- **怎麼做**：正常 70 kg，單次 IV bolus `0.33 g/kg = 23.1 g`、2 分鐘打完，從基礎態積分 150 min。把各清除通量在整段時間上積分，分配葡萄糖去向。
- **關鍵數字**：葡萄糖 91.5 → peak `250 mg/100ml`（t=2 min），52 min 恢復；insulin 11 → 40 µU/ml；glucagon 75 → 6 nU/ml（被血糖＋insulin 上升壓下去）。
- **去向（佔周邊清除 40,170 mg）**：
  - `F5` CNS/RBC：24,503 mg（**61.0%**）← 最大
  - `F4` 肌肉/脂肪：11,202 mg（27.9%）
  - `F3` 腎臟：4,465 mg（11.1%）
- **答案＋機制**：大部分跑去 **CNS＋紅血球（F5, 61%）**，因為它是很大、幾乎不靠 insulin 的 sink；F3 要血糖超過 ~180 才開，這裡 peak 才 250，所以只貢獻 11%。用 Forrester 的話講：bolus 把血糖頂高→開 F6（∝r）→insulin 上升→一邊周邊清除血糖、一邊（用抑制型 −tanh 閘門）壓 glucagon。`∫NHGB = +16,855 mg`（正號）代表整段窗口肝臟淨上是個**來源**（血糖清完後基礎肝輸出又主導）。

### Ex2 — insulin 的「hump（駝峰）」

- **題目**：Fig 12.5（正常人重複葡萄糖脈衝）的 insulin hump 為什麼會出現？Fig 12.7 肥胖者也有類似 hump，為什麼？
- **怎麼做**：(i) 正常人，遞增重複脈衝（0.5,1,2.5,5,10,20,40 g，在 0,30,70,110,180,270,400 min），跑 700 min。(ii) 肥胖者，單次 23.1 g IVGTT。
- **結果**：(i) hump = True，insulin 在 ~450 min 回升到 ~37 µU/ml（先掉到 ~31）。(ii) hump = True，~105 min 二次回升到 ~32（先掉到 ~22；peak 36 vs basal 11）。
- **機制（兩個 hump 同一根源）**：`F6 ∝ r`，而 `r` 從儲存池 `s` 慢慢回填（`dr/dt = k21·s − k12·r − F6`）。「你不可能分泌手上沒有的 insulin，而 r 不能瞬間補滿」。
  - Fig 12.5：每個脈衝把 r 抽乾，但脈衝間隔比回填／清除時間還短 → r 被反覆抽乾又過量回填，再加上多隔室延遲（`r→l→p→i`）把延遲貢獻疊起來 → 血漿 insulin 在脈衝間**不是指數衰減，而是累積成延遲的 hump**。
  - Fig 12.7（肥胖）：同樣的池動力學，但這次是**參數**造成而不是重複輸入。`b6=0.5`（正常 ~0.0923）把 F6 閘門變很陡 → 一次負荷就觸發 r 的劇烈抽乾－回填；`m02=0.13` 讓下游清得慢 → 池子 overshoot、r 一回填分泌又再開 → 即使血糖反應接近正常，insulin 衰減曲線上也冒出異常 hump。

### Ex3 — 重複脈衝：糖尿病 vs 正常

- **題目**：把 Fig 12.5 脈衝序列套到糖尿病人，和正常人比。
- **怎麼做**：同一遞增序列套兩人跑 800 min，用同一個 canonical core。糖尿病用 Table 12.3 的分泌／攝取形狀改變，並把 insulin 驅動的肝臟（F2）與周邊（H4）攝取閘門**凍結**，再校正到它自己的升高操作點。

| 量 | Normal | Diabetic |
|---|---|---|
| Basal glucose | 91.5 | 140.0 |
| Peak glucose | 366 | 418 |
| Basal insulin | 11.0 | 7.0 |
| Peak insulin | 62 | 18.3 |
| 末次脈衝後恢復(min) | 462 | 524 |

- **誠實的建模選擇（要會講）**：Table 12.3 列 `F2=0.037`，但那是課本**未經 scale** 的單位。經過我的 `glucose_flux_scale=1e5`，字面值會變成 ~3700 mg/min 的肝臟「吸塵器」（~70× 正常基礎 F2≈52），把血糖夾平——生理上是反的。scale 一致的正確讀法是「F2/H2 被換成常數」＝糖尿病肝臟**不能再隨 insulin 升高去 ramp 攝取**，所以我把 F2 凍在正常基礎肝攝取附近、H4 凍在 Table 12.3 的 0.0012。
- **升高基礎不是靠凍結就跑出來的**：M1（葡萄糖自抑制）和 G1（glucagon 閘門）讓 91.5 變成很強的吸引子，光凍結會被拉回 91.5。所以糖尿病人也要校正到它自己的操作點 `DIABETIC_BASAL = 140/7/75`，用的是和正常人同一組未定死的比例（aw, a71, b52），**沒改任何回授形狀**。在這個低肝臟-insulin 的狀態下，**沒被凍結**的肝臟生產閘門 H1 自然就坐很高（~0.66 vs 正常 0.25）：肝臟生產不再被 insulin 壓制——這正是課本講的糖尿病機制，是**自然湧現**的而非硬塞。
- **結論**：糖尿病基礎血糖高（140）、基礎 insulin 鈍（7.0）；peak insulin 18.3 遠低於正常 62，所以 hump 被壓掉；清得慢、血糖疊在已經偏高的基礎上。標準 IVGTT 上這套配置恢復 ~100 min vs 正常 ~52 min（~1.9×），正是課本「~2× 慢恢復」。

### Ex4 — 一餐（60 min 輸注）vs IVGTT 脈衝

- **題目**：把葡萄糖不用瞬間 IVGTT 脈衝、而是 60 分鐘均勻輸入（一餐）：25 g 給 70 kg。和同總劑量 IVGTT 比。
- **怎麼做**：25 g 兩種給法——餐：`Ig=416.7 mg/min` 跑 [0,60]；IVGTT：~2 min bolus（`Ig=12,500 mg/min`）。**唯一差別是輸入的時間分布**。60 分鐘矩形輸注是真實腸胃 `Ra(t)`（葡萄糖出現速率，見 Dalla Man 2007）的一階近似。

| 指標 | Meal(60) | IVGTT(2) |
|---|---|---|
| Peak glucose | 143.9 | 263.4 |
| t-peak glucose | 59.9 | 2.0 |
| Peak insulin | 30.5 | 40.2 |
| Glucose 恢復(min) | 82.5 | 53.9 |

- **機制**：IVGTT 在 2 分鐘把 25 g 全倒進葡萄糖池，比任何清除通量都快 → 血糖立刻飆到 263。餐每分鐘才 417 mg，慢到清除通量（F3/F4/F5）＋肝臟生產抑制可以邊到邊清 → 峰值低又寬（143.9）。insulin 跟著「驅動強度」走：餐的緩升把 W、F6 閘門開得弱 → insulin peak 30.5（鈍），IVGTT 是尖峰 40.2。**這就是為什麼口服一餐對血糖恆定的壓力遠小於同劑量 IV bolus，也是為什麼耐受試驗用快速 bolus 來最大程度探測回授系統。**

### Ex5 — 高胰島素血症（hyperinsulinism）與 IV 葡萄糖搶救

- **題目**：(a) 模擬 hyperinsulinism（第一直覺：加大 a6），血糖低於 `20 mg/100ml` 判定死亡，報出致死設定與死亡時間。(b) 用 IV 葡萄糖搶救，要多少？
- **誠實的重構（重點）**：**單純加大 a6 殺不死人**。穩態時胰臟質量守恆逼 `F6=W`，血糖下降時 W 閘門關掉，所以內生 insulin 飽和（~40 µU/ml），血糖只掉到 ~78 就回升。這個恆定是**對的**——正常胰臟不會把你弄死。所以臨床的 insulin shock 需要一個**自主（autonomous）來源**（胰島素瘤 insulinoma 或過量注射），它不會在血糖下降時關閉。我把它忠實地模成一個自主腫瘤：`Ip_tumor = (M−1)·F6_basal`（`F6_basal=1.638×10⁴ µU/min`），M=1 是健康人。原生胰臟（W=F6 平衡、所有 tanh、所有 transfer rate）完全不動；死亡是 `ḡ−20` 的終止事件。

| a6 倍率 M | min ḡ | 死亡 | t_death(min) |
|---|---|---|---|
| 1.0 | 91.50 | 否 | — |
| 4.0 | 36.65 | 否 | — |
| 4.5 | 20.10 | **是** | 79.6 |
| 8.0 | 20.11 | 是 | 43.3 |
| 10.0 | 20.24 | 是 | 38.9 |

- **結果**：致死門檻是 **4.5×**；示範情境用 8×，在 t=43.3 min 死。搶救：在 240 min 臨床窗口連續滴注 IV 葡萄糖，用二分法找總劑量（全程 ḡ≥20）→ **最小搶救劑量 = 69.11 g／240 min**。低於它血糖谷底還是穿過 20、病人死；達到就把地板撐在 20。
- **限制**：腫瘤是永久的，所以 IV 葡萄糖是**爭取時間（temporizing），不是根治**（臨床要切瘤）——正好對應課本「短期治療＝大量 IV 葡萄糖」。劑量是針對某個定義好的窗口報的；窗口拉長就要等比例更多。報「永遠活下去要幾克」對永久來源是無定義的。

### Ex6 — insulin bolus：正常 vs 肥胖

- **題目**：快速注入 insulin `0.10 U/kg`、2 分鐘，看短暫低血糖，會死嗎？肥胖者重做。
- **怎麼做**：劑量 `0.10×70 = 7 U = 7×10⁶ µU`，矩形 `Ip(t)` 脈衝（3.5×10⁶ µU/min）打進血漿-insulin compartment，2 分鐘。各自從自己的基礎態起跑；死亡判定 `ḡ<20`。

| 受試者 | glucose 谷底 | insulin peak | 判定 |
|---|---|---|---|
| Normal | 20.08 | 1541 | **死亡**（t=21.4 min） |
| Obese | 59.83 | 1542 | 存活（103.6 min 恢復） |

- **機制（要會講的反直覺點）**：兩人收到**一模一樣**的 7 U，insulin peak 幾乎一樣（~1541），但血糖谷底差很多（20 vs 60）。差別**完全來自周邊清除 F4**：肥胖者把組織間 insulin 閘門 H4 凍在 0.0012、移動葡萄糖閘門（b42,c42），所以同樣的 insulin 洪水每分鐘清掉的血糖少很多。這是模型對 **insulin resistance** 的表現，而且在這裡是**保護性的**：正常人完全反應的組織把血糖一路壓穿 20 而死；抗性的肥胖者只掉到「低血糖但可存活」的範圍然後回升。正常人的結果剛好坐在致死邊界，但終止事件在不同解法與步長下都一致觸發，所以判定在模型內是穩健的。

### Ex7 — 一碗香草冰淇淋（normal/diabetic/obese）

- **題目**：模擬三種人各吃一碗冰淇淋的 glucose/insulin/glucagon 動態。
- **關鍵假設（要會講）**：一碗 ≈ 1 cup（~130 g）一般香草冰淇淋；USDA 每 100 g 約 23–24 g 碳水（幾乎全是糖）→ ~31 g。我採 **30 g 可消化碳水，當作 100% 變成血漿葡萄糖**（保守上界，實際上乳糖＋脂肪會拖慢吸收）。40 分鐘吃完，模成 `Ig=750 mg/min` 在 [0,40]（同樣是 Ra(t) 一階近似）。三人各從自己的基礎態起跑（diabetic 用和 Ex3 一樣的 140/7/75）。

| Subject | basal g | peak g | basal ins | peak ins | min glucagon | g 恢復(min) |
|---|---|---|---|---|---|---|
| Normal | 91.5 | 185.7 | 11.0 | 36.9 | 2.2 | 77.3 |
| Diabetic | 140.0 | 252.8 | 7.0 | 9.4 | 1.5 | 126.4 |
| Obese | 91.5 | 206.8 | 11.0 | 35.5 | 1.2 | 113.8 |

- **三種反應**：
  - **Normal**：升到 ~186 再乾淨清回 91.5，有漂亮的 first-phase insulin spike（11→37）。
  - **Obese**：血糖 peak 略高（~207）但形狀跟正常差不多（課本所謂「glucose 近乎正常」），但 insulin 衰減曲線上重現那個**異常 hump**（陡 F6 閘門＋較快 m02 清除）。
  - **Diabetic**：從升高的禁食基礎（140）起跑、peak 最高（~253）、恢復最慢（~126 vs 正常 ~77），insulin 老實地鈍（7→9.4）：攝取受損（F2,H4 凍低）＋生產沒被壓（H1 高）→ 更高更慢的 excursion。
  - 三人 glucagon 都被餐後血糖＋insulin 上升壓下去（F7 被兩者負向驅動），從 ~75 掉到 ~1–2 再回升。

校正掉那張「被低估的參數表」後，同一個 canonical core 把 Ex1～Ex7 的預期生理全部跑出來：CNS/RBC 拿走大部分葡萄糖負荷、hump 來自有限池分泌（`F6∝r`）、攤開的一餐壓力遠小於同劑量 IV bolus、糖尿病／肥胖／高胰島素／insulin 過量各有特徵。兩個要老實揭露的重構：hyperinsulinism 需要自主（insulinoma）來源（完整胰臟會自我限制）、糖尿病人要校正到它自己的升高操作點（正常基礎是強吸引子）。這些**都沒改模型的回授結構**。

# Part 2 — HIV 疫苗接種（sIC AIDS 模型）

本質上是做 Exercise 15.6 #5：把性活躍的 susceptible 以速率 `nu` 接種成 protected 狀態，保護以速率 `l` 消退（waning），然後回答四問。

## 2.1 sIC 模型在描述什麼（白話版）

人口分成 **12 個 compartments** ＝ 3 種疾病狀態 × 2 性別 × 2 年齡層：

- 疾病狀態：`S`（susceptible 易感）、`I`（HIV 感染但還沒發病）、`A`（臨床 AIDS）
- 性別：female `f` / male `m`
- 年齡層：age 1（出生～15，性前期）、age 2（16～死亡，性活躍）
- **只有 age-2 參與傳播。** 所以狀態向量是 `{S_f1, S_f2, S_m1, S_m2, I…, A…}`。

這是完整 IC 模型的刻意簡化：兩性行為相同、單一 AIDS 期、單一性活躍層（社會混合機率 `ρ=1`）、兩個年齡層。

### force of infection 為什麼是 frequency-dependent

HIV 是性傳染，人找伴侶數大致固定、不隨人口大小變，所以重要的是「可能伴侶裡有多少比例是有感染力的」，**不是密度**。對 age-2 female：

`λ_Sf2 = c·ρ·β_mf · I_m2/(S_m2 + I_m2)`（male 那條對稱）

- `c`：新伴侶取得率
- `β`：每段伴侶關係的傳播機率，**不對稱**：`β_mf=0.2` vs `β_fm=0.075`，男→女約 2.7× 容易（異性戀 HIV 的標準生物特徵）→ 這也是為什麼女性平衡盛行率比男性高。
- `I/(S+I)`：可能伴侶中有感染力者的**頻率**。注意 **A（臨床 AIDS）被排除在伴侶池外**（假設不再性活躍），所以分母只有 `S+I`——這點對後面「疫情種子要放哪」很關鍵。

### 主要參數（Table 15.2）

`α=1.0`（AIDS 額外死亡）、`β_fm=0.075`、`β_mf=0.2`、`c=2.35`、`γ=1.16`（表值，後面會改）、`μ=0.0227`（自然死亡）、`θ=0.2088`（生育力）、`ϑ=0.35`（**圍產期 perinatal 傳播機率**，感染母親生出感染新生兒的機率）、`ξ=0.0667`（age1→age2 老化率）。機制包含：生殖（只從 age-2 女性）、圍產期傳播、老化、AIDS 進展 `γ`（I→A）、AIDS 死亡 `α`、人口學死亡 `μ`。

### 一個守恆修正

課本把 `A_f2` 的老化流入印成 `ξ·I_f1`，但這違反個體守恆（會把 I_f1 重複計算、又漏掉 A_f1）。正確應該是 `ξ·A_f1`。改成這個之後，總人口平衡（`d/dt Σ狀態 = 出生 − 死亡`）在模擬中守恆到 ~10⁻¹³。

## 2.2 兩個關鍵的 modeling judgment（Part 2 的靈魂，一定會被問）

### (i) 為什麼把 γ 從 1.16 改成 0.1

兩性 frequency-dependent 模型的基本再生數是兩個跨性別再生數的幾何平均：

`R0 = c·√(β_mf·β_fm) / (μ+γ)`

- 表值 `γ=1.16` → 從感染到 AIDS 平均只有 `1/(μ+γ)≈0.85 年`（不到一年，**和課本自己說的 1–10 年矛盾**）；而且代進去 `R0≈0.24 < 1`，**疫情根本點不起來**（字面參數模擬確認種子熄滅，peak prevalence ~7×10⁻⁴），這直接和 Fig 15.5（HIV 變地方性流行）矛盾。
- 所以我改用生物上合理的 `γ=0.1` → 平均感染期 `1/(μ+γ)≈8.1 年`（落在課本 1–10 年內），`R0 = 2.35·√(0.2×0.075)/(0.0227+0.1) ≈ 2.35 > 1`，疫情會 invade，符合課本圖。
- 對應的群體免疫（critical vaccinated）門檻 `p_c = 1 − 1/R0 ≈ 0.574`。

### (ii) partner-pool convention：protected 要不要算進分母（最 load-bearing 的選擇）

疫苗加了兩個 protected compartment `P_f2, P_m2`（只在 age-2）。問題是：**P 要不要算進 frequency-dependent 分母？**

- P 是「性活躍、未感染」的人，所以**他們是合法的伴侶**——只是和 P 的伴侶關係不傳任何東西。所以正確分母是 `S+I+P`（A 仍排除）。**我採這個。**
- 為什麼關鍵：把 susceptible 移進 P 之後，會**稀釋**感染頻率 `I/(S+I+P)`——這**正是群體免疫的機制**。
- 如果反過來把 P 排除在分母外，疫苗者就被同時從分子和分母拿掉，人為地把感染比例撐高，**假性地抹掉群體免疫門檻**——疫苗會看起來在任何接種率都沒有臨界值。那是分母選擇的**人工假象**，不是疾病的性質。我只在 Q(c) 把它當 sensitivity check 報出來。
- `nu=0` 時 P=0，這個選擇沒影響，所以 baseline 和 condom 情境都不受影響。

### 疫情種子放哪

表 15.2 用 5 個 AIDS 男性（`A_m2=5`）當種子。但 A 被排除在 force of infection 外，**放在 A 的種子完全不能傳**（驗證：最大發生率剛好 0，疫情永遠不開始）。所以我改種 **5 個有感染力的男性 `I_m2=5`**。這是「讓疫情能點起來、又尊重 A 不傳播規則」的最小改動。

## 2.3 基準驗證（對 Fig 15.5）

修正後 baseline（nu=0）定性重現 Fig 15.5a：總人口早期成長（N(0)=8005 → ~22,900 約在第 48 年，因為高生育率）、HIV **不熄滅而到地方性流行**、女性盛行率 > 男性。模擬平衡盛行率 female≈0.77、male≈0.61、overall≈0.41，課本目標是 ~0.9 / ~0.75。**排序與持續性都對，絕對值偏低**（不意外，因為我為了讓疫情點得起來重校了 γ）。超過 10% 盛行率的時間約 34 年，和課本 ~20 年同數量級。

condom 情境（Fig 15.5b）照課本把兩個 β 折半 → 因為 R0∝√(β_mf·β_fm)，剛好把 R0×0.5 = `1.17`（只比 1 高一點點）。我的校正下平衡盛行率掉到很低（~0.001），比課本（~0.7/~0.45）跌更多。**方向對、量級分歧**，原因很有啟發：γ=0.1 時折半-β 的 R0 卡在 **near-threshold（剛過 1）** 的極敏感區，校正的小變動會大幅移動地方性流行水準。我**標示這個分歧而不去硬調**——這正是 Q(d) 會再出現的 near-threshold 敏感性。

## 2.4 疫苗延伸的設定

- **疫苗種類**：take（all-or-nothing，全有全無）型 + waning。在 P 裡的人視為完全保護（force of infection 不作用、P 不會流向 I），一部分以 `l` 速率失去保護回到 S。這是 `S→P→S` 流的最乾淨讀法。
- **標準情境值**：`nu=0.65/yr`、`l=0.1/yr`，對應 Garnett/Stover 的「65% 覆蓋、平均 10 年保護」。
- **waning ceiling（保護天花板）**：忽略人口學時，保護比例飽和在 `P/(S+P) → nu/(nu+l) = 0.65/0.75 ≈ 0.867`。所以即使這個速率，疫苗任一瞬間**最多只能保護約 87% 的合格池**，永遠不可能全保護。
- **成本累加器**：`dV/dt = nu·(S_f2+S_m2)`，`cost = $10×V`，和狀態一起積分（避免事後積分誤差）。每次 $10 計一次接種**事件**（正確地包含「保護消退後回到 S 又被重新接種」的人）。

## 2.5 逐題註解（Q a/b/c/d）

### Q(a) — 疫苗會不會讓疫情 peak-and-decline？

答案其實**比「peak-and-decline」更強**：因為可達保護比例 0.867 舒服地超過群體免疫門檻 `p_c=0.574`，疫苗把有效再生數壓到 1 以下：

`R_eff ≈ R0·(1 − nu/(nu+l)) ≈ 2.35×(1−0.867) ≈ 0.31 < 1`

所以**疫情一開始就點不起來**。

| | Baseline(nu=0) | Vaccine(nu=0.65) |
|---|---|---|
| Peak incidence | 790.6/yr（@47.8 yr） | 2.3/yr（@t=0，就是種子） |
| incidence 行為 | 升到大峰、維持高 | 單調下降 |
| Peak prevalence | 0.409 | 0.0010（@~4.6 yr） |
| prevalence @80yr | 0.408 | ≈0 |
| protected fraction | — | → 0.85 |

- **要會講**：疫苗下 incidence 在 t=0 最高（就是 5 個種子男感染幾個接觸者），然後**單調掉到幾乎 0**。prevalence 只有 ~0.001 的微小內部凸起（~4.6 年）然後降到近 0。**衰減不是瞬間**，因為既有的 I/A 庫存還要花 ~8–10 年進展、死亡才清掉；但 R_eff<1 沒有新傳播來補它，所以感染清除。protected fraction 飽和在 ~0.85（略低於 0.867，因為 μ 也作用在 P）。

### Q(b) — 疫苗成本

| T(yr) | 接種次數 | 成本($) | 避免感染 | $/避免感染 |
|---|---|---|---|---|
| 20 | 11,374 | 113,738 | 305 | 372 |
| 30 | 16,217 | 162,165 | 1,585 | **102** |
| 50 | 24,746 | 247,461 | 13,434 | 18 |

- **要會講**：總成本近乎**線性**成長，大部分花在前期一次性接種既有 susceptible 池；飽和後只是維持性地重接（消退者＋新進者）約 **407 次/yr ≈ $4,070/yr**。
- **cost-effectiveness 隨時間大幅改善**：早期 baseline 還沒起飛、沒什麼感染可避免，比值看起來貴（$372@20yr）；當 baseline 加速衝向 ~791/yr 峰值、疫苗組維持近 0 時，避免的感染長得比成本快，所以掉到 **$102@30yr**、$18@50yr。30 年的 $102 剛好落在 Stover & Garnett (2002)（IC／rural-Zimbabwe，$20/人基礎）回報的 $110–390 帶下緣，考量這裡 $10 單價、且正確 partner-pool convention 下疫苗幾乎避免**整個** baseline 疫情，是一致的。
- **可轉移的指標是「每避免一次感染的成本」，不是頭條總額**（因為絕對美元數依賴這個小的合成人口）。

### Q(c) — 最佳接種率（"optimum" 有兩個意思，都報）

**(1) 流行病學門檻 `nu_c`**：要 `nu/(nu+l) ≥ p_c` → `nu_c = l·p_c/(1−p_c)`。
- 理論值 `≈ 0.135/yr`（閉式解，是個**下界**，因為它漏掉兩個機制：圍產期傳播 `ϑ=0.35`（疫苗擋不掉的路徑）、以及人口補充＋μ 作用在 P）。
- **直接模擬量出的 `nu_c ≈ 0.366/yr`**（把微小感染種進已接種的無病人口，找早期成長率穿過 0 即 R_eff=1 的 nu）。標準 `nu=0.65` 舒服地在它之上，**確實控住疫情**。
- 注意這是 frequency-dependent 的「盛行率比例」門檻，不是「(I+A)/N→0」。因為 `α=1` 的嚴重 AIDS 死亡會讓整個人口在幾百年內趨向滅絕（即使 nu=0），絕對數會因錯誤理由崩掉，所以 invasion / R_eff 測試才是穩健訊號。

**(2) cost-effective 速率**：掃 nu，avoided infections 在過 nu_c 後**飽和**（過了門檻基本上 ~13,400 個可達避免都已避免，再加只是重接消退者）。diminishing-returns 的「膝點」（capture 99% 最大可達避免的最小 nu）在 **nu≈0.175/yr**（該處邊際成本 ~$122/額外避免）。標準 0.65 仍控住疫情但相對這個 cost-effective 膝點**過度接種**；其平均成本 $18/避免@50yr。

**sensitivity**：門檻隨 R0 走。c=3.0 → R0~3.0、nu_c~0.48；γ=0.18 → R0~1.42、nu_c~0.16。方向穩健（正確 convention 下總存在有限 nu_c，且 0.65 在合理範圍內都在其上），但 near-threshold（小 R0）時邊際薄。
**caveat**：若錯誤地把 P 排除，invasion 成長率在整段掃描都不穿 0，疫苗會看起來**沒有有限門檻**——這是分母選擇的假象，只報出來證明門檻結果是真的。

### Q(d) — 疫苗 vs 保險套

| Strategy | R0 / R_eff | 避免感染 | 成本($) |
|---|---|---|---|
| Baseline | R0=2.35 | — | 0 |
| Vaccination(nu=0.65) | R_eff=0.31 | 31,224 | 348,618 |
| Condoms(0.5β) | R0=1.17 | 30,857 | 0（未計價） |

- **兩者基本上都控住疫情**，但機制不同（保險套直接靠 β 壓 R0；疫苗把人移進 P）。
- **R_eff（門檻）**：疫苗 `R_eff=0.31<1`（invasion −0.040/yr），**嚴格跨過**消除門檻；保險套 `R0=1.17`，**還在 1 之上一點點**（invasion +0.086/yr），50% β 削減在這個 R0 還不夠跨門檻，但疫情慢到在 horizon 內等於被控住。
- **避免感染幾乎一樣**：疫苗 31,224 / baseline 31,235（殘留 11）、保險套 30,857（殘留 378）。疫苗只**微幅領先**，因為它嚴格把 R_eff 壓到 1 以下。兩者都把 peak prevalence 從 0.41 壓到 ~0.001。
- **成本基礎差很大，所以我拒絕硬選單一贏家**：疫苗有**明確**的 $348,618（80 年），且被 waning ceiling 0.867 卡住，要無限期重接消退者；保險套被模成永久 0.5× R0 削減、**未計價**——但「未計價」不等於零，真實行為改變計畫有它自己的預算（專題沒給）。要做美元對等比較，需要一個我們沒有的 condom 計畫成本。
- **near-threshold caveat**：保險套只比 1 高 ~17%，更高的 baseline R0（如更高伴侶率）會把 condom-R0 推明顯過 1、同時抬高疫苗的 nu_c——兩個判定在門檻附近都對 R0 敏感，這正是我明確報 R_eff 而不只看軌跡的原因。
- **誠實讀法**：流行病學結果是**接近平手**，疫苗微幅領先（嚴格跨門檻），兩者就現有計價方式**不能直接比成本**。

## 2.6 Part 2 小結

把 γ 重校到生物合理的 0.1（R0≈2.35）、種子放進 infectious 而非 AIDS compartment 後，`nu=0.65` 控住 HIV：`R_eff≈0.31<1`、疫情點不起來、prevalence 維持近 0 而非升到 ~0.41 地方性平台。成本有效（30 年 ~$102/避免，落在 Garnett/Stover 帶內），但標準速率相對 cost-effective 膝點（nu≈0.18）略過度接種。對保險套是大致平手——都控住，疫苗嚴格跨門檻、保險套剛好在 1 之上——但就現有計價不能直接比成本，兩個判定在門檻附近都對 R0 敏感。所有結論都建立在揭露的建模假設上，尤其是 γ 重校和讓疫苗有群體免疫效果的 partner-pool convention。

## 2.7 Anticipated Q&A（老師可能問的，附簡短回答建議）

1. **「你為什麼把 γ 從課本的 1.16 改成 0.1？這樣不是在湊答案嗎？」**
   不是湊答案，是修正一個自相矛盾的表值。1.16 給出 0.85 年的感染→發病時間，和課本自己寫的 1–10 年矛盾；而且 R0≈0.24<1，疫情點不起來、和 Fig 15.5 矛盾。0.1 給 8.1 年感染期（落在課本範圍內）、R0≈2.35，才能重現課本的地方性流行。

2. **「疫苗為什麼會有 herd immunity（群體免疫）效果？」**
   因為 force of infection 是 frequency-dependent，`λ ∝ I/(S+I+P)`。把 susceptible 移進 P 後，P 仍是合法但不傳染的伴侶，留在分母裡稀釋了感染頻率 I/(S+I+P)。這個稀釋就是群體免疫，讓 R_eff = R0·(1 − protected fraction)。

3. **「為什麼 protected fraction 不會到 100%？」**
   因為 take-with-waning：以 nu 進、以 l 退，穩態飽和在 `nu/(nu+l)=0.867`（再被 μ 作用在 P 壓低到 ~0.85）。所以最多保護 ~87% 合格池。

4. **「成本怎麼算的？$102 是什麼意思？」**
   成本 = $10 × 累積接種事件數（含重接消退者），和狀態一起積分。$102 是「30 年累積成本 ÷ 30 年累積避免感染數」＝每避免一次感染花 $102。它隨時間下降（baseline 越晚越爆，避免數長得比成本快）。

5. **「保險套和疫苗到底哪個好？」**
   就流行病學結果是接近平手：兩者都把盛行率從 0.41 壓到 ~0.001、避免感染數幾乎一樣（31,224 vs 30,857）。疫苗微幅領先，因為它嚴格把 R_eff 壓到 0.31<1，保險套的 R0=1.17 還在 1 之上一點。但成本不能直接比：疫苗有明確 $348,618 還要一直重接，保險套被當成無計價的永久 R0 削減——真實行為計畫其實有預算只是專題沒給。

6. **「partner-pool convention 為什麼那麼重要？」**
   它決定疫苗有沒有 herd immunity。P 算進分母（正確）→ 稀釋感染頻率 → 有有限 nu_c。P 排除（錯誤）→ 疫苗者同時離開分子分母 → 感染比例被人為撐高 → 門檻消失，疫苗看起來在任何速率都不能消除疫情。這是分母選擇的假象，不是疾病性質，所以我只把它當 sensitivity check。

7. **（Part 1）「你校正了 Cobelli 參數，那結果還算數嗎？」**
   算數，因為我只動了「沒被定死的 source/clearance 比例尺」（glucose_flux_scale、aw、a71、b52），這正是課本說這個 semi-phenomenological 模型的預期用法（scale 到特定病人）。我**沒動任何 tanh 形狀（b,c）或 transfer rate（mij,kij）**，basal 穩態與所有回授形狀完全不變。我也明說不宣稱這些是原始 Cobelli 係數。

8. **（Part 1）「為什麼單純加大 a6 殺不死人，要弄個腫瘤？」**
   因為正常胰臟有質量守恆 F6=W，血糖一降 W 閘門就關，內生 insulin 飽和、血糖只掉到 ~78 就回升——正常胰臟不會把你弄死，這是對的恆定。臨床 insulin shock 需要一個不隨血糖關閉的**自主來源**（insulinoma 或過量注射），所以我模成自主腫瘤 `Ip_tumor=(M−1)·F6_basal`，原生胰臟完全不動。

## 3. 誠實的 limitations 總結

整份專題刻意把「假設」和「限制」攤開，不藏。要記住的四大限制：

1. **Calibration（Part 1）**：Cobelli 的 Table 12.2/12.3 字面值跑不出課本圖，我做了有文件記錄的最小校正（glucose_flux_scale、aw、a71、b52）。這些**不是**原始 Cobelli 係數，是重現課本圖的擬合；只保證定性吻合。
2. **Near-threshold sensitivity（Part 2）**：condom 情境（R0≈1.17）和疫苗 R_eff 都坐在門檻附近，小的 R0／校正變動會大幅移動結果。這是為什麼 condom 盛行率量級和課本分歧、也是為什麼我報明確的 R_eff 而非只看軌跡。
3. **Small synthetic population（Part 2）**：絕對美元總額依賴這個小的合成人口（N(0)=8005），所以可轉移的指標是「每避免一次感染的成本」，不是頭條總額。
4. **單一 operating point**：Part 1 每個病人校到單一基礎操作點；Part 2 主要結論建立在單一標準情境（nu=0.65, l=0.1, γ=0.1）與 partner-pool convention 上。我做了 sensitivity（Q(c) 的 R0 掃描）但沒做完整參數不確定性分析。

> 一句話總結報告的態度：能跑出課本行為，但凡是需要「修課本」才跑得出來的地方，我都講清楚改了什麼、為什麼合理、以及我**沒有**宣稱什麼。
